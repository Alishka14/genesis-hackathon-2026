## Ограничение
Reference implementation демонстрирует совместимость форматов и корректность *одного* обучающего примера. Она не обеспечивает физическую изоляцию private truth в отдельном процессе, не покрывает требуемые размеры эпизодов, все четыре типа ошибок, два compound, baselines и hidden evaluation. Не запускать произвольного недоверенного агента в том же Python-процессе.

Любая работа вне перечисленного scope требует нового согласования. Все тесты должны отмечаться результатом реального запуска; репозиторий `main` не изменять без разрешения.
