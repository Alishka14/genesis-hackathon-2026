## LedgerGym — планируемый продукт

**LedgerGym** — проект RL-совместимой среды для проверки финансовых ИИ-агентов на синтетических данных. На этапе планирования определены компоненты: LedgerWorld, LedgerFault, LedgerSandbox, LedgerProof, LedgerScore. Дополнения: Causal Audit Benchmark, Evidence Quality Taxonomy и False Accusation Analysis.

**Текущий статус:** проектирование и подготовка планов. В основной ветке конкурсного кода пока нет; описание запланированных возможностей не означает, что они реализованы.

### Происхождение работы и использование ИИ

**Свой вклад команды (проектируется):** генератор синтетических финансовых сценариев, RL-инструменты, собственный matcher и диагностическая методология. По мере реализации этот раздел должен перечислять реальные файлы, авторов модулей и проверенные тесты.

**Открытые репозитории и сторонний код:** изучаем методы Diyaz Forge, Ghost Busters, Ghostproof, CheckList, Hypothesis, AgentDojo и других публичных проектов. На момент добавления этого раздела они указаны как **методологические источники**, а не как фактически скопированный код или установленные зависимости. Любое реальное включение должно быть отдельно зафиксировано с версией и лицензией.

**ИИ-инструменты:** ChatGPT использовался при обсуждении идеи, архитектуры, плана для четырёх человек, распределения задач и диагностических метрик. Фактическое использование ИИ для генерации или проверки конкурсного кода будет отмечаться после соответствующих работ; не заявляем ещё не выполненные действия.
