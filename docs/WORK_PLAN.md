# План — Genesis Hackathon 2026

1. **Research:** подтвердить конкурсные правила, ссылки и критерии.
2. **Scope:** зафиксировать свою часть командной задачи.
3. **Design:** согласовать архитектуру и критерии приёмки.
4. **Implementation:** писать конкурсный код только после разрешённого старта, по заданию.
5. **QA:** автоматические тесты, проверка демо, учёт ограничений.
6. **Delivery:** создать Pull Request, получить одобрение, подготовить сдачу.

Сдача проекта никогда не выполняется автоматически.
