# Genesis Hackathon 2026

**Формат:** Командное участие: только назначенный компонент.

**Сроки:** Предварительно: кейс 19 ноября, сдача 22 ноября, финал 28–29 ноября; подтвердить.

**Ссылка на конкурс:** https://www.instagram.com/genesis.studio.kz/

## Статус
Рабочее пространство создано. Здесь пока нет конкурсного кода или отправленной работы.

## Порядок работы
1. Подтвердить условия конкурса в `docs/COMPETITION_RULES.md`.
2. Уточнить команду, назначенную личную часть и разрешения капитана в `docs/SCOPE.md`.
3. Согласовать план в `docs/WORK_PLAN.md`.
4. После разрешённого старта выполнять задачи в ветках `agent/<роль>/<номер-задачи>` и предлагать изменения через Pull Request.
5. Слияние изменений и конкурсная подача — только после проверки и явного одобрения человека.

Не добавлять секреты, личные данные и конфиденциальные материалы организаторов. Отделять модельные расчёты от подтверждённых результатов.
