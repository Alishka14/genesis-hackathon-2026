Техническое задание требует: 4 типа ошибок, 2 compound-сценария, clean/hard-negative, reset/step, ровно 5 допустимых действий, шаговый лимит 100, изоляцию evaluator truth, один-к-одному evidence-aware matcher, 4 baseline, 10 открытых train + 10 dev эпизодов, тесты, одношаговую инструкцию проверки, траектории с полями `episode_id`, `step`, `action`, `observation`, `reward`, `terminated`, `truncated`.

**Важное соответствие формата:** `evaluation/trajectories.jsonl` остаётся action-only. Полный **7-полевой** экспорт реализован отдельно как `evaluation/submission/trajectories.jsonl` (см. `docs/verification/GATE3_RESEARCH_2026-11-21.md`). Убедиться, что в конкурсном пакете указан **правильный** файл; не передавать `private/truth.json` и `private/provenance.json` недоверенному агенту.

**Денежный допуск:** официальный PDF требует сумму «в явно указанном допуске», но не называет конкретное число; точный допуск в `score.py` — проектная политика, не официально подтверждённый числовой параметр. Политика дополнительных evidence IDs тоже требует проверки. Не менять scoring наугад перед сдачей.

**Ресурсы:** PDF предлагает Python 3.11, 2 CPU, 4 ГБ RAM, без GPU, 1 ГБ на решение, 60 с/эпизод, 100 шагов; это **предлагаемый** лимит в тексте кейса. Локальный профиль не сертифицирует соответствие инфраструктуре жюри.

## 4. Воспроизводимый выпуск (оператор Mac)

В `~/genesis-hackathon-2026-ledgergym`:

```bash
source .venv/bin/activate
git status --short
git rev-parse HEAD
python -m pytest -q -rs tests/test_isolated_runner.py tests/test_role3_runtime.py
RUN="$HOME/ledgergym-dev-$(date +%Y%m%d-%H%M%S)"
python3.11 -m ledgergym.company_dataset "$RUN" --evaluate --settlement-hard-negatives
ls -l "$RUN/evaluation/submission/trajectories.jsonl"
python3.11 -m ledgergym.dashboard --dataset "$RUN" --port 8765
```

Открыть `http://127.0.0.1:8765`, визуально проверить таблицы/Replay и остановить сервер `Ctrl+C`. В созданном `RUN` могут быть данные `private/`, поэтому **не загружать весь каталог в общий Drive без выборочного просмотра и согласованного разделения public/evaluator-only**. Для нового полного gate: использовать существующий проверенный wheelhouse, но **новые** пути `--bundle` и `--report`. Не удалять исходный коммит и не подменять итоговый SHA.
