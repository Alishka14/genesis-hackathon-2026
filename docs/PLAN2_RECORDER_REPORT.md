# План v2: журнал событий и единая проверка

21.11.2026. Ветка `agent/integration/plan2-recorder`, продолжение draft PR #16; версия пакета 0.1.0.dev17. Выполнены технические части LG-028 и LG-040 нового мастер-плана. Это промежуточный результат разработки, не конкурсная отправка.

## Что изменилось

- Новый `events.jsonl` фиксирует reset, переносимое действие, публичное наблюдение, reward и terminal flags. Случайные page tokens канонизируются; `info.score`, private truth/provenance и seed не добавляются. Oracle не экспортируется.
- `ledgergym-verify NEW_DIR` / `python -m ledgergym.verification NEW_DIR` запускает pytest, генерирует 10 train + 10 dev, выполняет четыре baseline и 60 replay, проверяет соответствие событий действиям. Есть log/JUnit, JSON-отчёт, elapsed этапов и SHA-256.
- Ошибки дают FAIL/exit 1, пропуски — PARTIAL/exit 2, успешный локальный прогон — PASS/exit 0. Пустой набор, сбой коллекции, pytest timeout и повреждённые артефакты не могут дать PASS. Существующая папка не перезаписывается.
- Старые actions-v1, summary, финансовые данные, API среды, reward и score сохранены. Контракт и ограничения: `EVENT_RECORDING.md`.

## Фактически выполненные проверки

Все три прогона выполнялись одной новой командой с default test scope, CPython 3.11.11 / pytest 8.4.2.

| Окружение | Тесты | Итог / exit | Время полной команды |
| --- | --- | --- | --- |
| macOS arm64, исходники | 267 PASS, 0 SKIP; в том числе 7 Docker | PASS / 0 | 32.786 s |
| macOS arm64, свежая venv и установленный wheel вне checkout | 267 PASS, 0 SKIP; в том числе 7 Docker | PASS / 0 | 35.284 s |
| Linux arm64, установленный wheel, network none, 2 CPU / 4 GiB | 260 PASS, 7 SKIP | PARTIAL / 2 | 27.648 s |

Linux не получает Docker socket/daemon, поэтому семь интеграционных проверок изоляции пропущены. Их успешный запуск относится к macOS-хосту. Образ CPython 3.11.11 slim-bookworm закреплён digest в существующем runner; подготовка образа выполнена отдельно с сетью. Linux установил все зависимости из wheels с `--no-index --require-hashes`; pip check прошёл. Лимиты контейнера не являются измерением peak RSS, CPU time не измерялся. Время относится к одному запуску, не к статистическому performance benchmark. Windows/amd64 не проверялись.

Новый набор добавил 23 теста; вместе с прежним тестом evaluation целевой прогон — 24 PASS. Покрыты повторяемость и переносимость страниц, отсутствие служебного feedback, closed reward, неизменность входов, invalid actions/submit, truncation, недостающие/лишние/изменённые события, ошибки и пропуски реального pytest, ошибка генератора и повторный запуск в существующую папку. До создания новых модулей тесты падали при импорте отсутствующих модулей.

Во всех трёх прогонах: 10 train + 10 dev, четыре baseline, 60/60 совпадений replay, **1548 событий** (60 reset, 1488 action, включая 60 terminal). У трёх итоговых файлов совпали SHA-256 между исходниками, установленным macOS-пакетом и Linux:

Все 161 файл нового dataset, старые trajectories и summary побайтово совпали с этапом payment matching. Отдельный verification.json включает измеренное время и поэтому не канонизируется.

Сохраняются прежние метрики на открытом синтетическом наборе: reconciliation TP=48 / FP=0 / FN=0, mean F1=1, mean reward=0.9524. Политика использует общий checker генератора — это контроль согласованности реализации, не независимый benchmark.

## Границы и дальнейшая работа

Recorder экспортирует фактические ответы доверенного replay; live Docker runner не изменён. Кодировщик предполагает публичный контракт среды и не очищает произвольные документы стороннего env от секретов. Весь каталог verification содержит private-эталоны разработки и служебные логи, его нельзя передавать недоверенному агенту. Старые и новые журналы действий/наблюдений отделены от диагностик оценщика.

PASS относится только к описанным локальным проверкам. Минимальные CAB-пары, design note, полный отчёт CPU/RAM, сверка первичных PDF и неутверждённых финансовых правил, независимый review, лицензия собственного кода, видео/презентация и сдача остаются открытыми. Публикация, merge и конкурсная отправка не выполнялись. Новых сторонних библиотек или реальных финансовых данных нет; реализация и тесты подготовлены Codex, участие ИИ отражено в PROVENANCE_AND_AI_DISCLOSURE.md.
