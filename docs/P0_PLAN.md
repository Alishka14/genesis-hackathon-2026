# LedgerGym P0 — рабочий план

Статус 20.11.2026: капитан разрешил начать разработку; команда из трёх участников. Назначения ниже — функциональные области, не имена людей. Правила первоисточников требуют сверки: PDF не предоставлены в текущем сеансе.

1. Контракт и оценка: независимо проверяемый evidence-aware matcher, точные F1/reward, тесты чистого эпизода, дублей, порядка и атак.
2. Финансовая модель: воспроизводимый чистый эпизод, четыре отдельно управляемых типа дефектов, два действительно взаимодействующих compound, clean/hard-negative, самопроверка evidence и инвариантов.
3. Среда: пять действий, корректный жизненный цикл, лимиты, Decimal calculator; внешняя изоляция agent runtime от закрытых файлов и evaluator.
4. Интеграция: сквозной прогон, четыре baseline, 10 train и 10 dev, безопасные траектории, офлайн-команда, фактический тест-отчёт и раскрытие использования ИИ.
5. После подтверждённого P0: causal/invariance pairs и диагностические расширения без изменения официальной формулы.

Интерфейс между областями: `docs/INTERFACES.md`. Каждая область требует независимых негативных тестов и обзора команды. Никакого merge, изменения доступа, публичной публикации или отправки без явного разрешения капитана.
